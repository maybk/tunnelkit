# 界面组件 (`frontend/src/components`)

按复用层级与业务领域组织的可复用 Vue 组件。

## 目录结构

- `ui/`：同步自 `shadcn-vue` 官方模板的基础 UI 控件（按 `components.json` 生成，尽量少修改以便升级维护）。
- `base/`：项目外观适配与必要的最小源码定制，不承载业务状态，不镜像官方全集。
- `common/`：跨业务复用的通用复合组件（弹窗、状态徽标、分段切换、内联提示、更新弹窗等）。
- `vpn/`：VPN 连接控制、状态概览、会话摘要与二次认证弹窗。
- `profile/`：节点基础连接、认证与安全、路由与 DNS 分区及双模编辑面板。
- `logs/`：连接日志工具栏、深色终端文本容器与日志查看面板。

## 开发规范

- **命名与写法**：组件文件使用 `PascalCase.vue`，统一采用 `<script setup lang="ts">`，双向绑定优先使用 `defineModel()`。
- **体积与职责**：按交互与业务职责组织组件；复杂草稿编排下沉至 `composables/`，校验规则放在 `validate/`，共享业务状态放在 `stores/`。
- **依赖约束**：禁止直接导入 `@/api/*`、`@bindings/*` 或 `@wailsio/runtime`。
- **基础层**：`base/` 只依赖 `ui/`、本层与 `lib/`；无定制需求直接使用 `ui/`。
