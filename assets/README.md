# 图标与品牌资源 (`assets`)

管理品牌矢量母版、图标生成配置与 Go 运行时内嵌图标。

## 目录结构

- `brand/`：唯一品牌图形母版与跨平台图标生成参数。
- `icons/`：通过 `main.go` 内嵌至二进制的窗口图标与三端托盘图标。

## 开发规范

- **单一母版**：品牌图形仅在 `brand/` 母版中维护；`icons/`、`build/` 平台图标与前端品牌标识均按配置统一生成，禁止手工修改。
- **规格约束**：窗口图标（`256×256`）主体为 `206×206` 安全区；托盘图标按平台分别使用 macOS `44×44` 黑色模板 PNG、Windows 多帧彩色 ICO 与 Linux `64×64` 彩色 PNG。
