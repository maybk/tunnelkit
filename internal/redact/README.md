# 凭据脱敏 (`internal/redact`)

供日志写入和历史日志读取复用的纯文本脱敏工具，仅依赖 Go 标准库，不依赖宿主或业务状态。

## 目录结构

- `text.go`：凭据字段识别、键值、认证头、URI 内嵌凭据与独立令牌脱敏编排。
- `path.go`：三端用户主目录路径中的操作系统用户名脱敏。

## 开发规范

- **仅依赖标准库**：严禁导入 `tunnelkit/*`、Wails 或第三方包，保持桌面端与辅助进程零耦合复用。
- **宁严勿漏**：不记录待脱敏原文；无法确定凭据边界时优先遮蔽，同时保留正常诊断字段，不承担网络拓扑匿名化或 XML 解析。

## 验证
