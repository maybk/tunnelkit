# 主题与样式

前端使用 Tailwind CSS v4 与 shadcn-vue（reka-nova），支持跟随系统、浅色和深色主题。

## 设计令牌

`src/styles/tokens/` 按职责分层：

| 文件            | 职责                                   |
| --------------- | -------------------------------------- |
| `palette.css`   | 基础调色板，不直接用于业务组件         |
| `semantic.css`  | 浅色与深色表面、品牌色及六类语义色     |
| `scale.css`     | 圆角、阴影、动效与桌面顶栏尺寸         |
| `theme-map.css` | 将令牌映射为 Tailwind 颜色和字号工具类 |

业务组件优先使用语义令牌。状态色通过 `constants/tone.ts` 统一映射；`lib/utils.ts` 的 `cn()` 支持自定义字号与颜色类同时使用。

## 组件定制

- `components/ui/` 保持官方模板同步边界。
- `components/base/` 承载项目样式适配和必要的源码定制，无差异组件直接使用官方实现。
- `components/common/` 组合跨业务交互，领域组件放在对应业务目录。

定制优先使用令牌、官方变体和插槽；必须修改结构时，只维护必要的组件。升级时核对属性、事件、插槽、焦点与键盘行为。

## 主题与布局

- `public/theme-init.js` 在首帧前读取缓存主题；`useAppearanceStore` 负责运行期同步和持久化。
- 原生滚动条由 `styles/base.css` 统一隐藏，保留滚轮、触控与键盘滚动；组件不预留滚动槽。
- 弹窗由基础组件统一限制宽高，保留视口边距，内容过长时可滚动。说明和更新弹窗使用中等宽度。
- 更新执行中隐藏操作区和关闭按钮，并拒绝关闭请求；失败后恢复操作。

## 状态反馈与动效

- 连接文案从真实后端状态派生，界面不得为播放动画延迟状态更新。
- `busyAction` 用于 API 调用期间的防重锁；`pendingAction` 用于尚未被状态事件确认的请求反馈。
- 断开按钮保留最短 350ms 的转圈展示；失败、切换节点、新连接或组件卸载时清理，不延迟网络断开。
- `StateText` 立即替换旧文案，只淡入新内容；连接时长使用稳定键，避免逐秒重播。会话卡片独立收拢退出。
- 动效只过渡实际变化的属性；Tailwind v4 的 `scale` 和 `translate` 需显式声明，不能仅过渡 `transform`。
- 全局响应 `prefers-reduced-motion`，持续呼吸使用 `motion-safe`。不为轻量反馈引入动画库。
