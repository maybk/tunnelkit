# 窗口、顶栏与菜单栏集成 (`internal/app`)

负责 Wails 桌面应用装配、平台顶栏配置、系统菜单栏（Tray）常驻及前后端状态同步。

## 目录结构

- `app.go`：应用依赖装配、Wails 服务注册、启动期旧更新备份清理、会话恢复与 `vpn:state` 事件推送。
- `window.go`：主窗口尺寸、三端标题栏样式与关闭窗口隐藏至菜单栏钩子。
- `dock_darwin.go`：macOS 窗口隐藏或恢复时同步切换 Dock 栏图标显隐。
- `dock_other.go`：Windows 与 Linux 平台下 Dock 显隐钩子的空实现。
- `tray.go`：系统菜单栏图标、快捷菜单渲染与连接状态同步。
- `quit.go`：三端统一退出守卫，异步停止活动会话并等待网络恢复，自动合并重复退出请求。
- `updater.go`：自更新检查器与 VPN 维护门禁桥接，下载校验通过后停止会话并在重启交接后触发退出。

## 开发规范

- **职责边界**：仅负责桌面宿主装配、窗口/托盘交互与事件桥接，不承载连接状态机或配置校验逻辑。
- **退出与更新安全**：正常退出或自更新重启前必须经由 `quit.go` / `updater.go` 停止活动 VPN 会话并确认宿主网络恢复完成。
