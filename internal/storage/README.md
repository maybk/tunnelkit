# 本地文件存储基础设施 (`internal/storage`)

统一管理 `~/.tunnelkit` 数据目录路径布局、跨平台原子文件替换与有界日志脱敏读取。

## 目录结构

- `paths.go`：数据根目录、`profiles.json`、`secrets.json`、`secret.key`、会话票据 `run/session.json` 及连接日志目录的标准路径解析。
- `atomic.go`：在目标同级目录创建临时文件，完成写入与 `Sync` 刷盘后原子重命名替换，失败时自动清理残留临时文件。
- `tail.go`：按字节与行数上限读取日志文件尾部，并对敏感键值与 Cookie 执行兜底脱敏。

## 开发规范

- **原子落盘**：所有持久化配置、加密凭据与会话票据写入必须经由 `atomic.go` 完成，严禁直接截断覆写原文件。
- **职责边界**：本包仅提供路径与文件 I/O 原语，不解析业务配置结构；日志尾部读取中的正则遮蔽作为纵深防御，不替代辅助进程侧的实时脱敏。
