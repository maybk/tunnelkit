# 通用工具 (`frontend/src/utils`)

提供跨模块复用的格式化、网络地址解析、时间计算、敏感信息脱敏与 DOM 判定函数。

## 目录结构

- `format.ts`：字节体积、包数量、RTT 延迟与多行列表格式化。
- `network.ts`：网关地址规范化、`host:port` 智能拆分、IPv4 与 CIDR 校验。
- `redact.ts`：日志复制中的凭据键值、认证头与 Cookie 脱敏。
- `time.ts`：连接持续时长、中文时长与日期时间格式化。
- `dom.ts`：可编辑元素与浮层判定。

## 开发规范

- 函数显式接收依赖，不读取业务状态或隐式访问全局 DOM。
- 第三方库适配放在 `lib/`，响应式交互编排放在 `composables/`。
